# Texture sources

PBR texture sets for the laboratory renderer (spec 18 §4, textures). Every set is a directory
`<set>/{albedo,normal,roughness[,metallic,ao]}.jpg`: albedo sRGB, the rest linear, normal maps
in the OpenGL convention (+Y up), 1024² (1K), re-encoded to stay under 1.5 MB per set. All
downloaded sets are **CC0 1.0 Universal** (public domain dedication, no attribution required,
redistributable); the two procedural sets are generated by `fetch_textures.py` in this
directory and are part of this repository. `fetch_textures.py` reproduces every file here
(deterministic for the procedural sets; the downloads are re-encoded at quality 88).

Notes

- ambientCG asset licence: https://docs.ambientcg.com/license/ (CC0 1.0). Poly Haven
  (https://polyhaven.com, also CC0) was surveyed via `https://api.polyhaven.com/assets?t=textures`;
  its catalogue has no clean machined-metal sets, so every download is from ambientCG.
- ambientCG map names → ours: `Color` → `albedo`, `NormalGL` → `normal`, `Roughness` →
  `roughness`, `Metalness` → `metallic` (dropped when constant: the material factor carries it),
  `AmbientOcclusion` → `ao` (kept for the floor only, where it is not constant).
- The renderer normalises albedo and roughness maps by their means (`gfx::Material::normalizeMaps`),
  so the table in `src/Lab/Materials.cpp` keeps the calibrated colour and roughness of every
  material and the maps carry the micro-structure only.
